# 🦦 Carpinchomon

¡Bienvenido a **Carpinchomon**! Un mini juego desarrollado como parte del **Curso de Programación Básica de Platzi**.

La lógica de combate está inspirada en el clásico "Piedra, Papel o Tijera", adaptada a un enfrentamiento entre carpinchos.

---

## 🚀 Estado del Proyecto
Actualmente, el proyecto se encuentra **en desarrollo**. Se están puliendo las mecánicas de combate y la interfaz de usuario.
La meta final es transformar la lógica actual en un:

* **Juego 2D con desplazamiento:** Para exploración y cumplimiento de objetivos.
* **Combate 1 vs 1:** Peleas mano a mano con mecánicas inspiradas en clásicos como **Street Fighter**.


## 🛠️ Tecnologías Utilizadas
Para este proyecto se utilizó tecnología web estándar (**Vanilla Stack**) para fortalecer las bases de programación:
* **HTML5:** Estructura semántica.
* **CSS3:** Estilizado y diseño visual.
* **JavaScript (Vanilla JS):** Lógica del juego, manipulación del DOM y gestión de eventos.



## 🎮 Cómo Jugar
1. **Selecciona tu mascota:** Elige a tu Carpinchomon para iniciar la batalla.
2. **Elige tu ataque:** Selecciona ataques de diferentes elementos.
3. **Batalla:** El sistema calculará el ganador basándose en la lógica de tipos.
